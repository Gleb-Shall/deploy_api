# Документация и скрипты для локальной разработки

Эта папка содержит скрипты и документацию, которые нужны только для локальной разработки и не используются на сервере.

## Скрипты для Cursor IDE

### `install-ecc-global.sh`

Установка конфигурации [ecc-universal](https://github.com/affaan-m/everything-claude-code) для Cursor IDE.

**Использование:**
```bash
# Установка в проект (рекомендуется)
./docs/install-ecc-global.sh typescript python

# Дополнительно скопировать в ~/.cursor/ (глобально)
./docs/install-ecc-global.sh --global typescript python
```

**Что делает:**
- Устанавливает правила, агентов, skills, команды и MCP-конфиг в `.cursor/` в корне проекта
- Опционально копирует команды в `~/.cursor/commands/` для глобального использования

**Примечание:** Обычно используется через npm-скрипт:
```bash
npm run cursor:install -- typescript python
```

### `cursor-rules-to-mdc.sh`

Автоматически переименовывает файлы правил из `.md` в `.mdc` в `.cursor/rules/`.

**Зачем:** Cursor IDE требует расширение `.mdc` для правил, чтобы они отображались в настройках. Скрипт запускается автоматически после `npm run cursor:install`.

**Использование вручную:**
```bash
./docs/cursor-rules-to-mdc.sh
```

---

**Важно:** Эти скрипты не нужны на сервере и не должны копироваться при деплое. Они используются только локально для настройки Cursor IDE.
